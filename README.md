<h2 align="center">💫 About Me</h2>

<p align="center">
I'm a Full Stack Engineer building web and mobile products end to end — from backend architecture to polished user experiences. My core stack is React, React Native, Node.js, Express, with MySQL and MongoDB on the data side, deployed on AWS. I've shipped a multi-tenant SaaS booking platform, an offline-first wellness app with Realm sync, and internal operations tools for clients. Right now I'm expanding into DevOps and cloud infrastructure — Docker, Kubernetes, Ansible, CI/CD, and Infrastructure as Code — to think about systems beyond just the application layer. Outside of engineering, I'm an NGO member, chess player, and always building something of my own on the side.
</p>
